## 阶段 C：离线缓存与断网可读（✅ 已完成 2026-11-17）

**目标**：断网冷启动不再是错误页。读过/看过的内容（书架 JSON、封面、页图）留在磁盘上，
离线时按"缓存内容"展示，并明确告诉用户"现在是离线"。

- HTTP 层缓存接口放进 `komga_api`（纯 Dart，不依赖 drift），实现放 app 的 Drift 表；
  传输层 GET 成功写缓存、网络类失败读缓存并上报离线状态。
- 缓存分区按服务器地址（多服务器不串数据），页图/封面按字节预算 LRU 淘汰，JSON 不参与字节淘汰。
- 设置页显示缓存占用、可清空；书架/系列/阅读器显示离线提示。
- 验收：缓存表单测（LRU/预算/清空/分区）、传输层回退单测（命中/未命中/404 不回退）、
  离线提示 widget 测试、黄金图（离线态）。

**落地**：`komga_api` +11 测试、app +17 测试、新增 `library_offline@phone_light` 黄金图；
文档 `docs/offline-cache.md` + ADR 0003。**

**明确不做**：整库镜像、离线登录（凭据仍从钥匙串读，离线只影响内容）。

## 阶段 D：阅读器补完

**目标**：把"翻页"从能用做到顺手，并让离线阅读可预期。

**进度**：D1 缩略图跳页 + 预取、D2 整本下载（进度/取消/删除）、D3 书末"下一本/回系列"均已完成（2026-11-17）。

- 页图预取窗口（前后 N 页），取消过期请求，避免快速翻页堆积。
- 缩略图导航：跳页面板带页缩略图网格，当前页高亮。
- 整本下载：系列详情/阅读器内"下载整本"，显示进度、可取消、可删除；下载完成的标记。
- 书末行为：读完最后一页给出"下一本 / 回到系列"。
- 验收：预取/取消逻辑单测、下载队列状态机单测、缩略图面板黄金图、阅读器黄金图不回归。

## 阶段 E：书架与系列

**目标**：让"找书"和"管理阅读状态"闭环。

**进度**：E1 继续阅读、E2 排序/筛选、E3 系列标记已读/未读均已完成（2026-11-17，接口均经真实实例验证）。

- 继续阅读（Komga `ondeck`）在书架顶部成行，读完即从行内消失。
- 排序（标题 / 添加时间 / 最近阅读）与已读状态筛选（未读 / 在读 / 已读）。
- 系列详情：标记已读 / 未读（单本与整系列），操作后原地刷新。
- 验收：筛选/排序查询参数契约测试（对照真实 OpenAPI）、状态回写测试、书架黄金图更新。

## 阶段 F：设置与多服务器

**目标**：一个 App 管多个 Komga，且用户能看见本地占用的空间。

- 服务器列表（保存多个地址/账号），一键切换、重命名、删除；切换后书架/系列重建。
- 存储管理：进度库与内容缓存占用、清空缓存、清空离线内容。
- 关于页：版本、开源许可、隐私说明入口。
- 验收：服务器存储读写测试、切换后 provider 重建测试、设置页黄金图（手机/平板/墨水屏）。

## 阶段 G：国际化与中文字体

**目标**：默认跟随系统语言，中英文完整，中文不再依赖系统字体碰运气。

- `flutter_localizations` + ARB（`lib/l10n/`），文案全部外置；语言设置（跟随系统 / English / 中文）。
- 中文黄金图：测试环境加载中文字体子集，保证中文排版可验证。
- 验收：`flutter gen-l10n` 无缺失 key、语言切换测试、中文黄金图。

## 阶段 H：形态适配与无障碍

**目标**：平板不是放大的手机，墨水屏不是深色主题。

- 平板/折叠双栏（书架 + 系列详情并排），`WindowSizeClass` 一次性决策。
- 墨水屏：对比度/灰度选项、翻页无动画、可关闭阴影；大按钮布局。
- 无障碍：语义标签、最小点击区域、屏幕阅读器顺序、动态字号（1.3×）不溢出。
- 硬件：音量键翻页（Android），iOS 常亮通道实现（仅 CI 编译验证，明确标注未真机验证）。
- 验收：平板双栏黄金图、语义测试、1.3× 字号无溢出、硬件键映射单测。
